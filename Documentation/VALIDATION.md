# 検証記録

Unity 2022.3.22f1、WindowsのGPU描画で、自作の4色テスト映像をRenderTextureへ出力して検証しました。

- シェーダーのコンパイル
- モード1/2の映像差し替えと上下左右
- モード3は手持ちカメラの位置に一致した場合のみ差し替え
- 通常視点・通常ミラー・顔ミラー・範囲外・無効状態の除外
- 枠を回転した場合、カメラが逆を向いた場合の描画
- 上下／左右反転、正方形出力での余白なし／全体表示
- Prefabに実行時独自スクリプト・Colliderが含まれないこと
- 設置ごとのマテリアル分離、テンプレートの非変更

VRCのグローバル値をUnityで再現したテストです。実際のVRCクライアントでの撮影を代替するものではありません。配布版の実機テストは未実施です。
